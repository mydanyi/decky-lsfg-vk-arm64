# r5: accepted private-device baseline

I accepted the final visual result on my physical KONKR Pocket FIT Elite on 2026-09-11. The source snapshot is based on plugin v0.12.8 with Armada ARM64/lsfg-vk 2.0 integration.

## Regression addressed

r4 automatically enabled an experimental native paired-pacing path whenever 2x and a positive base cap were selected. It also replaced ordinary DXVK/VKD3D caps with zero. In camera-motion testing in Monster Hunter Rise, removing the experimental pacing variable improved aggregate output from about75.8 to99.6FPS. Those two captures had slightly different positions and did not prove all frametime spikes were eliminated.

r5 does not enable that scheduler. It preserves positive DXVK/VKD3D caps, clears inherited caps at zero, and retains the tested prefer_gmem policy for2x with caps1–72. Its installer recognizes r4 launchers even when the native binary is unchanged, regenerates them using existing profile data, and leaves a current installation alone on the next startup.

The pre-package A/B test used driver caps0; r5 restored the actual saved cap72. The final acceptance is my subsequent physical visual test of r5, not an assertion that the earlier A/B numbers were measured from the r5 package.

## Verification

- Regression tests first failed on the r4 behavior: pacing re-enabled/caps zeroed, and an identical-core upgrade left the stale launcher intact.
- 70 backend and launch-option tests passed after the fix.
- 10 lifecycle tests passed against the extracted private ZIP, including same-core launcher upgrade and second-start idempotence.
- All26 packaged files matched the installed plugin; the active ARM64 library matched the supplied native payload. The saved configuration was unchanged.
- Ordinary Steam launch loaded the runtime with the saved caps and no experimental pacing override.
- I took over the final visual testing and confirmed it passed.

The private native payload is not included here. This acceptance is specific to the tested device and scenarios. Adaptive frame generation, a minimum-input-FPS threshold and NPU acceleration are not implemented. Broad all-game certification and complete elimination of occasional long frames are not claimed.
